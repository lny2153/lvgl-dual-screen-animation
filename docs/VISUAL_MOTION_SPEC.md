# VISUAL + MOTION SPEC

本规范只以 Figma 基线、原始参考 MP4/GIF 与标准化 JSON 为准。坐标均为最终 TFT 像素，不允许按 PC 窗口尺寸重新排版。

- 左屏：`648 × 200`
- 右屏：`240 × 240`
- 背景：纯黑 `#000000`
- 参考时间基：60 fps；实现必须按毫秒求值，不能按帧数累加
- 默认曲线：`cubic-bezier(0.5, 0, 0, 1)`
- 双屏：共享同一个 `transition_id`、状态快照和 `t0_ms`，在同一 LVGL tick 更新

## 1. 最重要的可见性规则

左屏主视觉区在任一时刻只能属于一个模式：

```text
EYES       默认/识别中的小眼睛
FOOD       食材图标 + 食材名
WARNING    超重/电量警告专用表情 + 气泡
STATUS     居中的连接/去皮/记录成功圆环
```

**EYES / FOOD / WARNING / STATUS 永不共存。** Figma 同时画出眼睛和苹果只为标注各自位置，不是一张运行时画面。切换时必须先让旧模式完全退场，再让新模式入场；禁止长期交叉叠加。

右屏也只允许一个主模式：

```text
PLUS_ONLY | PLUS_RING | ADD_RING | FINISH_HOLD | UPLOAD_SPINNER |
SAFETY_PULSE | CHARGE_RING | OFF
```

实现建议：每次进入模式先调用统一的 `hide_all_primary_layers()`，再只显示目标模式所需对象。不要依赖 z-index 掩盖错误共存。

## 6. 通用运动规则

1. 位置、尺度、透明度使用 smooth 曲线；环形进度的“随用户手指增长”和加载旋转可以线性。
2. 模式切换遵守 `旧对象退场 → 0–150ms黑场/中心点接力 → 新对象入场`。不要用两张大图交叉淡化。
3. 成功环统一语法：`侧面椭圆(scaleX≈0.08) → 翻到正圆(scaleX=1)并放大 → 指针/勾绘制 → 文案出现 → 保持 → 缩退`。
4. 实时重量不做数字滚动、弹簧或缓动；以10–20Hz显示最新值。
5. 所有动画按 `elapsed_ms = now - t0` 取值；PC目标60fps，固件至少稳定30fps。低帧率只能降低采样，不能改变总时长。
6. 双屏转场只启动一次。左屏NO_OP或右屏NO_OP也要持有同一状态快照，禁止重建造成闪黑。

## 8. 原生重建、固定播放与缺口

## 9. 视觉验收硬门槛

- 任意截图中不得同时看到默认眼睛和食材图标。
- 任意截图中不得同时看到业务加号环与安全脉冲/充电环/上传点阵。
- M004、M006、M008必须存在旧对象完全退出后的接力点。
- M013切换时食材、当前重量、总重量像素位置不得变化。
- M015切换时营养槽和右屏不得变化。
- M006后只清当前值；M008/M0091后保留顶部已提交总计；M007仅在保存ACK后清总计。
- 所有双屏动画从同一个`t0_ms`开始；肉眼不得出现一屏先响应、另一屏明显后响应。
- 稳定态不得出现模拟器控制文字、事件名、触点编号、调试框或非设计卡片。
